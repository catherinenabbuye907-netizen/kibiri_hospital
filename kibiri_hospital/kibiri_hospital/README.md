# KIBIRI HOSPITAL
## Web-Based Hospital Management Information System
### Project Description
The Kibiri Hospital Management Information System (HMIS) is a web-based application designed to improve the management of hospital information and daily operations.

### Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

### Main System Modules
User Authentication
Patient Management
Doctor Management
Appointment Management
Consultation Management
Laboratory Management
Pharmacy Management
 Administration

### Installation
1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create the database named kibiri_hospital.
6. Import the SQL database file.
7. Configure the database connection.
8. Open http://localhost/kibiri_hospital/
